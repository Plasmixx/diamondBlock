# Security Policy

## Supported Versions

The following versions of this project currently receive security updates.

| Version        | Supported |
| -------------- | ---------- |
| v1.1.0-beta   | ✔️ |
| < v1.1.0-beta | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly so we can keep users safe.

### How to report
Send all security-related reports to **security@diamondblock.org**.
You may also submit a private GitHub Security Advisory through the repository’s Security tab.

### What to include
- A clear description of the vulnerability  
- Steps to reproduce the issue  
- The potential impact  
- Any suggested fixes or patches  

### What to expect
- We will acknowledge your report within **48–72 hours**  
- You will receive a status update within **7 days**  
- If the vulnerability is confirmed, we will begin working on a fix and coordinate a responsible disclosure timeline  
- If the report is not accepted, we will explain why  

### Disclosure process
We follow responsible disclosure practices. Details of confirmed vulnerabilities will not be published until a fix is available. Credit will be given to reporters unless anonymity is requested.

### Scope
We consider vulnerabilities related to:
- Blocking bypasses  
- Permission escalation  
- Data exposure  
- Integrity or reliability of the blocking engine  

Non-security bugs (UI issues, feature requests, performance problems) should be reported through the standard issue tracker.
