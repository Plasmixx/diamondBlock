# diamondBlock
I'm making an app where you can block apps on your phone to increase productivity for iOS, Android, Google Pixel, etc. You can solve problems, wait out the timer, or tap your phone with a friend's to take accountability. There will also be emergency exit keys, and you'll start with 3, just in case something happens. User can make an allow/blocklist to block specific apps, or to block all apps except a chosen few. I may also add an ad blocker to this in the future but we'll see.

I'm working on learning Swift so I can get this on iOS to try it, and our code will always be open source, and this project is strictly not for profit. The only way for the developers to make money off of this project is strictly through optional donations through the app that do not grant any sort of reward, ever. Emergency exit keys will also never be for sale. We only use buymeacoffee and Patreon as our donation channels, it is not us if it is a website other than those two.
